Universal OpenWrt Firmware Packages

Zero-dependency, standalone native binaries with embedded React PWA frontend. Hand-crafted and statically compiled with musl libc for all OpenWrt processor architectures.

Latest Release: v0.1.0-beta • Single-binary daemon (< 2 MB RAM)
One-Command Router Installation (MIPS Little Endian Example)
wget https://github.com/lucian-sins/waypoint/releases/download/v0.1.0-beta/waypoint-openwrt-mipsel.tar.gz && tar -xzf waypoint-openwrt-mipsel.tar.gz && sh waypoint-openwrt-mipsel/install.sh
